# FreshGo – Grocery App UI/UX Design

## Overview
FreshGo is a simple grocery delivery mobile app UI designed for a UI/UX internship task. The app focuses on clean design, product browsing, and easy shopping experience.

## Features
- Welcome screen
- Product listing screen
- Search bar
- Category selection
- Product details page
- Add to Cart functionality
