# FreshGo – Grocery App UI/UX Design

## Overview
FreshGo is a simple grocery delivery mobile app UI designed for a UI/UX internship task. The app focuses on clean design, product browsing, and easy shopping experience.

## Features
- Welcome screen
- Product listing screen
- Search bar
- Category selection
- Product details page
- Add to Cart functionality

## Tools Used
- Figma

## Objective
To design a modern and user-friendly grocery shopping mobile interface using basic UI/UX principles and soft color combinations.

## Conclusion
This project helped improve my mobile UI design skills, layout planning, and user experience understanding.
